# CSS / Material UI Classes

| Class | Description |
|-------|--------------|
| `.filterBar` | Horizontal flex container for filters |
| `.objectListCard` | Card for object list |
| `.objectDetailsCard` | Card for details and tabs |
| `.legend` | Small text block for legend |
| `.detailsSection` | Typography group for object attributes |
| `.eventsTable` | Table styling for events tab |

### Material UI Theme
- Primary color: `#1976d2`
- Secondary color: `#9c27b0`
- Background: `#f5f5f5`
- Typography: Roboto, 14–16 px
