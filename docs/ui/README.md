# Loading Process – Objects Manager

This project implements a two‑column dashboard built with React and Material UI.

## Main Features
- Filter bar with dropdowns, search, “Add Object” button, and an `Actually` checkbox
- The checked `Actually` mode loads all objects with `status=active` and presents their details read-only; inactive objects are excluded and service dates/values do not filter the results. Unchecked preserves the existing flow.
- Left panel: list of objects with legend
- Right panel: details card with tabs and events table
- Responsive layout using Material UI Grid
