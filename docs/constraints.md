# 9	Ограничения
-	API имеет лимиты по запросам
-	SQLite — файл базы данных: однописательная модель, не подходит для распределённой записи и масштабирования на несколько подов без дополнительного механизма; требует `PersistentVolume` для сохранности данных.
- 	SQLite — файл базы данных: однописательная модель, не подходит для распределённой записи и масштабирования на несколько подов без дополнительного механизма; требует `PersistentVolume` для сохранности данных.
- 	Требование для рабочей среды: обеспечить единственный pod для записи. В Kubernetes это означает разворачивать сервис с одной репликой, монтирующей PVC (`replicaCount: 1`). Запуск нескольких реплик для записи приведёт к риску повреждения БД.
