# 2. Цели и задачи проекта

## 2.1 Цели

-	Создать удобный инструмент для управления объектами оборудования.
-	Обеспечить прозрачность состояния объектов.
-	Снизить риски пропуска сроков обслуживания.
-	Автоматизировать расчёты и обновления данных.

## 2.2	Ключевые задачи

-	Реализовать UI для отображения объектов.
-	Обеспечить API для CRUD операций.
-	Реализовать модуль расчёта значений.
-	Обеспечить интеграцию с внешними сервисами.
