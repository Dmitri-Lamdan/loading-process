# 7 Нефункциональные требования (расширенные)
## 7.1	 SLA / SLO
-	Доступность системы: 99.5%
-	Среднее время отклика API: ≤ 200 мс
-	Максимальное время отклика: ≤ 1 сек

## 7.2	Масштабируемость
-	горизонтальное масштабирование backend
-	возможность вынесения модулей в микросервисы

- Развёртывание в Kubernetes: использование `Namespaces` (dev/staging/prod), HPA, ресурсных запросов/лимитов и стратегий rolling update для безопасного обновления сервисов.

## 7.3	Логирование и мониторинг
-	логирование всех API запросов
-	логирование ошибок
-	мониторинг через Prometheus / Grafana

## 7.4	 Безопасность
-	JWT аутентификация
-	HTTPS
-	RBAC (ролевой доступ)
-	защита от инъекций
